# Hafta 3

Her ödev kendi klasöründe. Klasör içinde:

- `girdi/`: `dag.jpg` (gri, sisli dağlar) ve `sis.jpg` (renkli sisli yol, gri tonlamada okunur)
- `hazir_fonksiyonsuz/`: ödevin istediği çözüm, kod + `cikti/`
- `hazir_fonksiyonlu/`: aynı iş OpenCV fonksiyonlarıyla, kod + `cikti/`

İki çözümün çıktı görüntüleri piksel piksel aynı.

| Ödev | Klasör | Sonuç |
|---|---|---|
| 1. Min-max doğrusal ölçekleme | [odev1-kontrast-germe](odev1-kontrast-germe/) | `dag` 0-237 → 0-255, `sis` 92-249 → 0-255 |
| 2. Histogram, CDF, histogram eşitleme | [odev2-histogram-esitleme](odev2-histogram-esitleme/) | `sis` std 37.28 → 74.33 |
